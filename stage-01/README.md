# Этап 1 — утверждён

Первый этап курсовой работы защищён и одобрен преподавателем. Его материалы считаются замороженными.

- `report_approved.pdf` — утверждённый эталон.
- `report.tex` — соответствующий ему LaTeX-исходник.
- `report.pdf` — локальная проверенная сборка.
- `usecase_*.png` — утверждённые диаграммы прецедентов.
- `description.txt` и PDF с заданием — исходные материалы этапа.

Не изменяйте файлы этой папки при выполнении следующих этапов. Если второму этапу понадобится текст или оформление первого, копируйте нужные материалы в `../stage-02/`, сохраняя оригиналы здесь.
