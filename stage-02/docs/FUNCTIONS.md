# Контракты SQL API

19 внешних функций; 13 внутренних функций и триггерных обработчиков. SQL-протокол ошибок: 40001/40P01 требуют повтора всей транзакции; P0002 — объект не найден; 23503 — FK.

## `free_intervals`

Максимальные свободные диапазоны в конечном окне; можно исключить переносимую бронь.

- Параметры: `p_equipment bigint,p_window tstzrange,p_ignore bigint DEFAULT NULL`.
- Результат: `SETOF tstzrange`.
- Ошибки: 22023: некорректное окно.
- Гарантии: Предварительный снимок; объединение броней и технических периодов.
- Покрытие: UC-01; FR-05,10; BR-2,3,10; T42

## `equivalent_equipment`

Свободные единицы с требуемой функцией и допуском на весь интервал.

- Параметры: `p_user bigint,p_capability bigint,p_period tstzrange`.
- Результат: `SETOF equipment`.
- Ошибки: Пустое множество при отсутствии вариантов.
- Гарантии: Не резервирует найденные слоты.
- Покрытие: UC-01; FR-11; BR-1,5; T40

## `find_alternatives`

До 12 вариантов в горизонте; пересекает свободные интервалы со сроками допусков.

- Параметры: `p_user bigint,p_equipment bigint,p_capability bigint,  p_period tstzrange,p_horizon interval DEFAULT interval '30 days',p_ignore bigint DEFAULT NULL`.
- Результат: `equipment_id, period, priority`.
- Ошибки: 22023: неверный диапазон или горизонт.
- Гарантии: Сортировка BR-6: 1,2,3; затем время и id.
- Покрытие: UC-01/02; FR-10–12; BR-5,6; T13,19,26,28,46

## `offer_alternatives`

Сохраняет предложения к существующей брони; прежние предложения устаревают.

- Параметры: `p_booking bigint,p_horizon interval DEFAULT interval '30 days'`.
- Результат: `integer: число предложений`.
- Ошибки: P0002: бронь отсутствует.
- Гарантии: Выбор пользователя не имитируется; предложения не занимают слот.
- Покрытие: UC-01/02; FR-12,15,17; BR-7; T13,20

## `create_booking`

Подтверждает будущую бронь; p_user — удостоверенный пользователь.

- Параметры: `p_user bigint,p_equipment bigint,p_capability bigint,  p_start timestamptz,p_end timestamptz,p_purpose text`.
- Результат: `bigint: id брони`.
- Ошибки: 23514: допуск/архив/недоступность; 23P01: пересечение; 22000: обратный диапазон.
- Гарантии: Атомарный INSERT, триггер и EXCLUDE.
- Покрытие: UC-01; FR-06–08; BR-1–4; T01–09; C01,C04

## `request_booking`

Обёртка создания: сохраняет причину отклонения без исключения для ожидаемого конфликта.

- Параметры: `p_user bigint,p_equipment bigint,p_capability bigint,  p_start timestamptz,p_end timestamptz,p_purpose text`.
- Результат: `booking_id либо error_code`.
- Ошибки: Ожидаемые 23514/23P01 возвращаются; прочие исключения передаются выше.
- Гарантии: Запись отказа сохранится только при COMMIT внешней транзакции.
- Покрытие: UC-01/03; FR-08,22; T38

## `cancel_booking`

Владелец либо администратор отменяет будущую активную бронь с причиной.

- Параметры: `p_actor bigint,p_booking bigint,p_reason text`.
- Результат: `void`.
- Ошибки: 42501: чужая бронь; 23514: прошлая/терминальная бронь или существующий сеанс.
- Гарантии: Отмена и уведомление атомарны; история сохраняется.
- Покрытие: UC-01; FR-09,21; BR-8; T06,07,11

## `select_alternative`

Владелец либо администратор подтверждает сохранённое предложение.

- Параметры: `p_actor bigint,p_alternative bigint`.
- Результат: `void`.
- Ошибки: 23514: устаревший вариант; 23P01: конкурентная бронь; 42501: нет прав.
- Гарантии: Блокировка обеих единиц; повторная проверка допуска, функции и календаря.
- Покрытие: UC-01/02; FR-13; BR-5–7; T16–18,44

## `report_fault`

Активный человек сообщает о неисправности без автоматического изменения доступности.

- Параметры: `p_actor bigint,p_equipment bigint,p_description text`.
- Результат: `bigint: id сообщения`.
- Ошибки: 42501: неактивный автор; 23503: нет оборудования.
- Гарантии: Сохраняется сообщение и аудит.
- Покрытие: UC-02; FR-16; T21

## `register_unavailability`

Техник либо администратор регистрирует ТО или подтверждает поломку. NULL p_end — неизвестный конец поломки.

- Параметры: `p_actor bigint,p_equipment bigint,p_kind text,  p_start timestamptz,p_end timestamptz,p_reason text,p_report bigint DEFAULT NULL`.
- Результат: `bigint: id периода`.
- Ошибки: 42501: роль; 23514: несоответствие сообщения/периода; 23503: ссылки.
- Гарантии: Период, маркировка будущих броней, варианты и уведомления в одной транзакции.
- Покрытие: UC-02; FR-14–17; BR-3,7; T12–15,22–25; C02,C03,C05

## `edit_maintenance`

Изменение периода и причины активного ТО либо его отмена.

- Параметры: `p_actor bigint,p_unavailability bigint,p_start timestamptz,  p_end timestamptz,p_reason text,p_cancel boolean DEFAULT false`.
- Результат: `void`.
- Ошибки: 23514: неактивное ТО/иная причина; 42501: роль.
- Гарантии: Новые затронутые брони маркируются; отмена не подтверждает их сама.
- Покрытие: UC-02; FR-14,15; BR-7,8; T20

## `equipment_state`

Состояние на момент p_at: archived, fault, maintenance, available.

- Параметры: `p_equipment bigint,p_at timestamptz DEFAULT clock_timestamp()`.
- Результат: `text`.
- Ошибки: NULL при неизвестной единице.
- Гарантии: Единый вычисляемый источник состояния по всем причинам.
- Покрытие: UC-02/03; FR-03; T22,27,29

## `resolve_unavailability`

Техник либо администратор записывает результат и закрывает активную причину.

- Параметры: `p_actor bigint,p_unavailability bigint,p_result text`.
- Результат: `text: итоговое состояние`.
- Ошибки: 23514: причина уже закрыта/ещё не началась; 42501: роль.
- Гарантии: Сохраняется вид работы work_kind (maintenance/repair); остальные события продолжают блокировать.
- Покрытие: UC-02; FR-18; BR-3,8; T27,29

## `open_session`

Владелец либо администратор открывает фактическую работу в плановом интервале.

- Параметры: `p_actor bigint,p_booking bigint`.
- Результат: `bigint: id сеанса`.
- Ошибки: 23514: бронь/допуск/время/доступность; 23505: сеанс уже есть.
- Гарантии: Один сеанс; блокировка оборудования и проверка начала.
- Покрытие: UC-01; FR-19,20; BR-9; T10,30,31

## `close_session`

Закрывает работу. p_comment обязателен при действии администратора за владельца.

- Параметры: `p_actor bigint,p_session bigint,p_comment text DEFAULT NULL`.
- Результат: `void`.
- Ошибки: 23514: повторное закрытие/нет комментария; 42501: нет прав.
- Гарантии: Фактический конец, комментарий и completed сохраняются атомарно.
- Покрытие: UC-01; FR-19,20; BR-8,9; T32–34,52,53,57

## `create_reminders`

Создаёт напоминания о будущих подтверждённых бронях до p_until; запускается планировщиком.

- Параметры: `p_until timestamptz`.
- Результат: `integer: число новых уведомлений`.
- Ошибки: Нет ожидаемых бизнес-ошибок.
- Гарантии: Частичный UNIQUE и ON CONFLICT: идемпотентность.
- Покрытие: UC-01; FR-21; T43

## `equipment_metrics`

Плановая и фактическая загрузка, объединённый простой, процент утилизации и число отказов за окно.

- Параметры: `p_window tstzrange`.
- Результат: `equipment_id, planned_seconds, actual_seconds, downtime_seconds, utilization_percent, conflicts`.
- Ошибки: 22023: окно не конечное/пустое.
- Гарантии: Сначала union диапазонов, затем пересечение с окном; без двойного счёта.
- Покрытие: UC-03; FR-22,23; T39,56,57

## `grant_admission`

Администратор назначает допуск с основанием и сроком.

- Параметры: `p_actor bigint,p_user bigint,p_type bigint,p_start timestamptz,  p_end timestamptz,p_basis text`.
- Результат: `bigint: id допуска`.
- Ошибки: 42501: нет роли admin; 23514: интервал; 23503: ссылки.
- Гарантии: Допуск и аудит сохраняются в транзакции.
- Покрытие: UC-03; FR-04; BR-1; T45–48

## `revoke_admission`

Администратор отзывает допуск без удаления истории.

- Параметры: `p_actor bigint,p_admission bigint`.
- Результат: `void`.
- Ошибки: 42501: роль; 23514: уже отозван/не найден.
- Гарантии: При повторном подтверждении и начале работы отзыв учитывается.
- Покрытие: UC-03; FR-04; BR-1,8; T49,50
